# Match3Game

Match3Game is a classic match-three puzzle game developed in C#. The game involves aligning three or more identical items in a row or column to clear them from the board and earn points. The goal is to achieve the highest score possible within a limited number of moves or time.

## Project Overview

Match3Game is developed using C# and provides a fun and engaging puzzle experience. The game includes various features such as different levels, power-ups, and a scoring system.

### Features

The game includes:
1. **Match-Three Mechanics**: Align three or more identical items to clear them from the board.
2. **Levels**: Multiple levels with increasing difficulty.
3. **Power-Ups**: Special items that can be used to clear more items or achieve higher scores.
4. **Scoring System**: Earn points by clearing items and complete levels with the highest score possible.
5. **User Interface**: A user-friendly interface with intuitive controls.

## Technologies Used

- **C#**: The primary programming language used for game development.
- **Unity**: (Optional) If the game is developed using the Unity game engine.

## Project Structure

The project structure includes several directories and files such as game assets, scripts for game logic, and Unity scenes (if using Unity).

## Usage

### Prerequisites

To run or develop the game, you need to have the following installed:
- **Unity**: If the game is developed using Unity, install the Unity Editor.
- **Visual Studio**: For C# development.

### Running the Game

1. Clone the repository:

    ```bash
    git clone https://github.com/barissolcay/Match3Game.git
    cd Match3Game
    ```

2. Open the project in Unity (if using Unity) or Visual Studio.

3. Play the game from the Unity Editor or build and run the executable.
